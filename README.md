# multi-robot-coordination

Программный комплекс для анализа методов координации исполнителей в мульти-робототехнических транспортных системах.

Выпускная квалификационная работа бакалавра, МАИ.

- Автор: Егор Тарасов, М8О-409Б-23
- Научный руководитель: Киндинова В. В.

## О проекте

Настольное приложение на Java, которое моделирует работу группы складских роботов и позволяет сравнить методы их координации: распределение заданий и планирование маршрутов без столкновений. По результатам экспериментов можно выбрать подходящий метод и оценить, сколько роботов нужно складу.

## Стек

Java 21, Maven, JavaFX, JUnit 5

## Статус

Проект в начале разработки: изучение предметной области и проектирование.
